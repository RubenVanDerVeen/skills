**Proposed shape:** command `commands/full-cycle.md` (`/full-cycle <feature>`), no new skill folder needed (orphan command per AGENTS.md). One approval gate after spec and one after plan by default; "at once" in the invocation collapses both. Explicit anti-stall rule: never end the turn between phases or tasks.
